# 2026_trip — ทริปครอบครัว 3 วัน 2 คืน (4 แผนให้เลือก)

ทริปสำหรับ **6 ผู้ใหญ่ + เด็ก 2 ขวบ (+ หมา 1 ตัว ถ้าสะดวก)** เดินทางจากกรุงเทพฯ ด้วยรถยนต์ส่วนตัว 2 คัน
โจทย์หลัก: **ไม่เกิน 5–6 ชั่วโมงจากกรุงเทพฯ / เน้นปูราคาถูก / ที่พักไม่เกิน 10,000 บาทต่อคืน (รวมทุกคน)**

## 4 แผน

| แผน | โซน | ขับจาก กทม. | จุดเด่น | ที่พัก 2 คืน |
|---|---|---|---|---|
| **A** | ระยอง–จันทบุรี | 3.5–4 ชม. | ปูถูก + พูลวิลล่าโต๊ะพูล + รับหมา | 14,000–16,000 |
| **B** | หัวหิน–ปราณบุรี | 2.5–3 ชม. | ใกล้สุด + กิจกรรมเด็กเยอะ | 8,000–19,800 |
| **C** | บางสะพาน–บ้านกรูด | 4.5–5 ชม. | ทะเลเงียบ ปูราคาชาวบ้าน | 7,200–14,000 |
| **D** | กาญจนบุรี | 2.5–3 ชม. | ธรรมชาติริมน้ำ ไม่เน้นทะเล | 8,000–13,200 |

## คำแนะนำสั้น ๆ

- **ปูถูก + พูลวิลล่าโต๊ะพูล + งบไม่เกิน 10,000/คืน** → แผน A จันทบุรี (วัชระ&ภัทรมน 7,000–8,000/คืน)
- **เหนื่อยน้อยที่สุด** → แผน B หัวหิน–ปราณบุรี (บ้านคาร์เมน/บ้านคอนทราสต์)
- **ปูถูกที่สุด + ทะเลเงียบ** → แผน C บางสะพาน (Baan Klang Aow)
- **ไม่อยากไปทะเลซ้ำ** → แผน D กาญจนบุรี (BOHO STORY)
