# 2026_trip — ตัวเลือกที่พักทริปทะเลตะวันออก

หน้าเว็บช่วยครอบครัวตัดสินใจที่พักสำหรับทริป 6 ผู้ใหญ่ + เด็ก 2 ขวบ (+ หมา 1 ตัว ถ้าสะดวก)
โซนระยองและจันทบุรี 13 พูลวิลล่า พร้อมราคา สเปก ที่ตั้ง สถานที่ใกล้เคียง และรีวิว

## เปิดดู

- หน้าแรก: [`index.html`](index.html)
- แผนการเดินทาง (ฉบับร่าง): [`travel-plan.html`](travel-plan.html)
- ตัวเลือกที่พัก: [`accommodation-comparison.html`](accommodation-comparison.html)

## ฟีเจอร์

**แผนการเดินทาง (`travel-plan.html`)**
- แท็บแยก 2 วัน 1 คืน (ระยอง) / 3 วัน 2 คืน (จันทบุรี) / คู่มือซื้อปู / เคล็ดลับ & Checklist
- กำหนดการรายชั่วโมง งบประมาณแยกบรรทัด
- การ์ดสถานที่ท่องเที่ยวพร้อม **รูปภาพ + ลิงก์ Google Maps + ลิงก์แหล่งที่มาของรูป**
- Checklist ก่อนจองที่ติ๊กแล้วจำค่าไว้ในเครื่อง

**ตัวเลือกที่พัก (`accommodation-comparison.html`)**
- **กดการ์ดที่พักเพื่อเปิดหน้ารายละเอียดเต็ม** พร้อมแกลเลอรีรูปภาพ (เลื่อนดูรูปได้)
- รูปภาพจริงของแต่ละที่พัก เก็บไว้ในโฟลเดอร์ [`images/`](images) (ใช้งานได้แม้ไม่มีอินเทอร์เน็ต)
- กรองตามโซน / มีโต๊ะพูล / รับหมา / ติดทะเล / งบไม่เกิน 10,000 บาท
- เรียงตามราคา หรือคะแนนรีวิว
- ปุ่มโหวตที่พัก + แถบอันดับ (เก็บคะแนนในเครื่องที่เปิด)
- **วิดีโอรีวิวจาก YouTube** ของแต่ละที่พัก (thumbnail + ลิงก์) — 7 หลังมีคลิปตรงตัว, ที่เหลือมีลิงก์ค้นหา
- พิมพ์ / บันทึก PDF
- ตารางเปรียบเทียบทั้ง 13 หลัง

## แหล่งที่มาของรูป

- รูปที่พัก: จากเว็บไซต์/เพจ/หน้า listing ของที่พักแต่ละแห่ง
- รูปสถานที่ท่องเที่ยว: Wikimedia Commons และ Flickr (CC) — มีลิงก์แหล่งที่มาใต้การ์ดทุกใบ

> รูปทั้งหมดเป็นภาพประกอบจากประกาศ/คลังภาพสาธารณะ ไม่ใช่ภาพที่ถ่ายตอนเราไปจริง

## หมายเหตุ

ราคาและรีวิวเป็นข้อมูลอ้างอิงจากประกาศ/แพลตฟอร์มช่วง พ.ย. 2569
ไม่ใช่วันที่เข้าพักจริง — ต้องยืนยันกับที่พักก่อนชำระเงินทุกครั้ง
