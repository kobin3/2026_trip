# 2026_trip — ตัวเลือกที่พักทริปทะเลตะวันออก

หน้าเว็บช่วยครอบครัวตัดสินใจที่พักสำหรับทริป 6 ผู้ใหญ่ + เด็ก 2 ขวบ (+ หมา 1 ตัว ถ้าสะดวก)
โซนระยองและจันทบุรี 13 พูลวิลล่า พร้อมราคา สเปก ที่ตั้ง สถานที่ใกล้เคียง และรีวิว

## เปิดดู

- เว็บหลัก: [`accommodation-comparison.html`](accommodation-comparison.html)
- หน้าแรกสำหรับ GitHub Pages: [`index.html`](index.html)

## ฟีเจอร์

- **กดการ์ดที่พักเพื่อเปิดหน้ารายละเอียดเต็ม** พร้อมแกลเลอรีรูปภาพ (เลื่อนดูรูปได้)
- รูปภาพจริงของแต่ละที่พัก เก็บไว้ในโฟลเดอร์ [`images/`](images) (ใช้งานได้แม้ไม่มีอินเทอร์เน็ต)
- กรองตามโซน / มีโต๊ะพูล / รับหมา / ติดทะเล / งบไม่เกิน 10,000 บาท
- เรียงตามราคา หรือคะแนนรีวิว
- ปุ่มโหวตที่พัก + แถบอันดับ (เก็บคะแนนในเครื่องที่เปิด)
- พิมพ์ / บันทึก PDF
- ตารางเปรียบเทียบทั้ง 13 หลัง
